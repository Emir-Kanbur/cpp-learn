# Katkı Rehberi

Bu depo C++ öğrenme notları ve örneklerinden oluşur. Katkı verirken içeriklerin öğretici ve sade kalmasına dikkat edin.

## Katkı Adımları

1. Depoyu fork edin.
2. Yeni bir branch açın (`feat/yeni-konu` gibi).
3. Değişikliklerinizi yapın.
4. Yeni `.cpp` dosyalarının derlendiğini kontrol edin.
5. Açıklayıcı bir commit mesajı yazın.
6. Pull Request açın.

## İçerik Kuralları

- Dosya adları konu odaklı ve anlaşılır olmalı.
- Örnekler mümkün olduğunca tek kavrama odaklanmalı.
- Gereksiz bağımlılık eklenmemeli.
- Kod C++ standardına uygun derlenebilir olmalı.

## Commit Mesajı Önerisi

- `feat: yeni for döngüsü örnekleri`
- `docs: readme güncellendi`
- `fix: switch-case örneği düzeltildi`
