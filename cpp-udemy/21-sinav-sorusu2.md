## Aşağıdaki kod blokları çalıştırıldıktan sonra w değeri ne olur?

# Soru 1:

int x = 5, y = 9, z = 7.4, w;

w = (z > x) - (y <= 11);

cout << w;

(z>x) => true olur 1 değerini alır
(y<=11) => true olur 1 değerini alır

Cevap 0 olur.

# Soru 2:

int x = 5, y = 9, z = 7.4, w;

w = z > x - y <= 11;

cout << w;
