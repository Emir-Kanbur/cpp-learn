## OPERATORLER

## Karşılaştırma Operatörleri

# (==) Eşit                                         4 == 5 => false 7 == 7 => true

# (!=) Eşit Değil                                   4 != 5 => true 7 != 7 => false

# (>)  Büyük                                        4 > 5 => false 7 > 5 => true 7 > 7 => false

# (<)  Küçük                                        3 < 7 => true 

# (=>) Büyük veya Eşit                              4 >= 5 => false 5 >= 5 => true

# (<=) Küçük veya Eşit                              3 <= 3 => true 3 <= 5 => true 3 <= 1 => false

## Mantıksal Operatörler

# (&&) Ve / AND                                    (10 < 3) && (4 < 7) && (3 < 7) => false

# (||) Veya / OR                                   (3 > 1) || (4 > 5) => false

# (!) Not / NOT                                    !(3 > 1) => false !(10 > 20) => true
