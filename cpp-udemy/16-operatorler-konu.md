# Operatörler

## Karşılaştırma Operatörleri

| Operatör | Anlamı | Örnek |
| --- | --- | --- |
| `==` | Eşit | `7 == 7` → `true` |
| `!=` | Eşit değil | `4 != 5` → `true` |
| `>` | Büyük | `7 > 5` → `true` |
| `<` | Küçük | `3 < 7` → `true` |
| `>=` | Büyük veya eşit | `5 >= 5` → `true` |
| `<=` | Küçük veya eşit | `3 <= 5` → `true` |

## Mantıksal Operatörler

| Operatör | Anlamı | Örnek |
| --- | --- | --- |
| `&&` | Ve | `(10 < 3) && (4 < 7)` → `false` |
| `||` | Veya | `(3 > 1) || (4 > 5)` → `true` |
| `!` | Değil | `!(3 > 1)` → `false` |
